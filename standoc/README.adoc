= Metanorma StanDoc document models

Information models for the Metanorma StandardDocument ("StanDoc") model itself — the shared layer every flavour profile builds on, together with the BasicDocument ("BasicDoc") base.


This directory is the `standoc` flavour of the
https://github.com/metanorma/standoc-models[standoc-models] monorepo (formerly
the standalone `metanorma-model-standoc` repository).

== Layout

* `models/` — LML (`.lml`) model sources
* `images/` — generated model diagrams, committed
* `build-config.yml` — the flavour's schema set for LXR grammar-package
  generation

Diagrams regenerate from `models/` via the root `Rakefile` (`rake standoc`).
Grammar sources live in `grammars/` at the monorepo root — see the root
README.
