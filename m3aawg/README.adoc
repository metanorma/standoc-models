= Metanorma M3AAWG document models

Information models for Messaging, Malware and Mobile Anti-Abuse Working Group (M3AAWG) best practices, based on the Metanorma StandardDocument ("StanDoc") model.


This directory is the `m3aawg` flavour of the
https://github.com/metanorma/standoc-models[standoc-models] monorepo (formerly
the standalone `metanorma-model-m3d` repository).

== Layout

* `models/` — LML (`.lml`) model sources
* `images/` — generated model diagrams, committed
* `build-config.yml` — the flavour's schema set for LXR grammar-package
  generation

Diagrams regenerate from `models/` via the root `Makefile` (`make m3aawg`).
Grammar sources live in `grammars/` at the monorepo root — see the root
README.
