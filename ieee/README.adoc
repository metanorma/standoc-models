= Metanorma IEEE document models

Information models for IEEE standards, based on the Metanorma StandardDocument ("StanDoc") model.


This directory is the `ieee` flavour of the
https://github.com/metanorma/standoc-models[standoc-models] monorepo (formerly
the standalone `metanorma-model-ieee` repository).

== Layout

* `models/` — LML (`.lml`) model sources
* `images/` — generated model diagrams, committed
* `build-config.yml` — the flavour's schema set for LXR grammar-package
  generation

Diagrams regenerate from `models/` via the root `Rakefile` (`rake ieee`).
Grammar sources live in `grammars/` at the monorepo root — see the root
README.
